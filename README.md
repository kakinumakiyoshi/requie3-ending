# requie3-ending
## 上映モード（モニター演出）

- `control.html`：上映コントロール（PCの手元で操作）
- `theater.html`：モニター画面（モニターに全画面で表示）
- エンディングアプリ（`index.html`）で判定すると、結果が自動でコントロールとモニターに届きます（同じPC・同じブラウザ内）。
- 映像・BGMは `media/` フォルダ、流すタイミングは `theater-config.js` で設定します。今入っているのは仮素材です。
- ネットがない会場でも動きます：事前にネットのある場所で、使うPCのChromeでこのアプリ（エンディングアプリ・上映コントロール・モニター画面）を一度開いておくと、本体と素材がPCに保存されます（`sw.js`）。
- 進行表：`theater-config.js` の `scenes` に、開場→配役発表→OP→読み込み時間（タイマー）→調査→議論→エンディングの順で並んでいます。順番・時間・背景はここで変えられます。
