# requie3-ending
## REQUIEⅢ 上映（1台のPCで全部やる）

- 当日は **`上映を起動.command` をダブルクリック**。このフォルダの中身を、そのPCの中だけで動かします（インターネットは使いません）。Chrome で上映コントロールが開きます。
  - フォルダは SSD に置いたままでも、PC にコピーしてもよい。
  - 上映が終わるまで、起動したときに出る黒いウィンドウ（ターミナル）は閉じない。
  - Mac の `python3` を使います（無いときは画面の案内に従って入れる）。
- `control.html`：上映コントロール（PC の画面で、いつでも操作）
  - 「進行」タブ：進行表・タイマー・配役・エンディングの上映。
  - 「エンディング判定」タブ：選択・生存者・犯人の勝敗を入れて判定（中身は `judge.html`）。判定した結果は「進行」の「エンディング」に自動で届く。ルカの選択（撃つ／撃たない）は「エンディング」の欄でも押せる。
- `theater.html`：モニター画面。プロジェクター（HDMI）をつないでから「モニター画面を開く」を押すとプロジェクター側に開く。プロジェクター側を一度クリックすると全画面。
- `index.html`：前のエンディングアプリの URL。開くと上映コントロールへ移る。
- 映像・BGM は `media/` フォルダ、流すタイミングと進行表は `theater-config.js`。
- 進行表：`theater-config.js` の `scenes`（開場→OP→配役発表→読み込み→ルール説明→各フェーズ→クライマックス→エンディング）。順番・時間・背景はここで変えられます。
- 予備：GitHub Pages（https://kakinumakiyoshi.github.io/requie3-ending/）でも同じものが動きます。一度開いておくと、ネットがなくても保存済みのもので動きます（`sw.js`）。
